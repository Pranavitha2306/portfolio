Personal project · Healthcare

Patient email triage with safety built in

Problem
Clinic inboxes mix emergencies with billing and scheduling questions. Replies need to be fast, but never unsafe.
Data
Nine fictional clinic policy documents and made-up patient emails. It's a demo, with no real patient data.
Approach
A LangGraph agent reads emails from Gmail, classifies urgency with OpenAI, and drafts replies grounded in policies retrieved from Pinecone. A keyword red-flag check catches emergencies even if the LLM misses them, a fixed fallback reply is used when no policy matches, and staff approve every draft through a FastAPI review API. Runs on PostgreSQL and Docker with pytest and GitHub Actions CI.
Human-approvedevery reply, with emergencies flagged first
